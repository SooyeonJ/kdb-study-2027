## 261107 스터디 대비
산은 문제 구성
일반적으로 1번 문제눈 DS 출제, 나머지 과목 1문제 씩 나눠서 출제

주간 문제 수·구성 
- 공통 : 10문항 (추후 객관식 3-5문제 추가할 것)
- 성욱 : 시험 임박했을 경우, 문항 조금 늘려서 빠르게 연습하면 좋을 것 같음 / 빈출 위주로 출제하면 좋겠음
  
문제 출제 방식 및 순서
- 불참 시에도 출제는 진행, 수연 -> 성욱 -> 경인 -> 소정 -> 승혜 순
- 매주 목요일까지 문제(md) - 파일명 통일(1회차_OS_수연) / 각자 해설(pdf) 깃헙 업로드 / 금까지 문제 취합
- 문제 취합 : 담당자가 알아ㅓㅅ 하고, 당일에 같이 문제 
1) 매주 담당자 - 스터디룸 에약, md 문제 취합, DS 1번 문제(소문항 4개) + 랜덤 약술형 1문제 출제 
- 경인 : 서술형 40점(소문항 4개 포함) 배점 문제는 주별 각자 출제, 나머지 8문제 - 4명 * 2문항씩 출제
- 성욱 : 1번 DS 문제의 경우, 7·9급 범위 및 코드 문제 참고하여 출제할 것 / 산은 출제 형식이랑 아예 비슷하게 하면 좋겠음
- 수연 : 스터디룸 예약 + 1번문제(소 4문항) + 9문항 합치기까지 진행하면 좋겠음 
- 소정 : 너무 산은 포커싱만 하기보다는, 전체 범위로 출제하면 좋을 것 같음


스터디 진행·채점 
- 진행 시간 : 2h (예약 - 2.5h), 토 11시 / 목요일 - 스터디룸 예약 및 정산, 불참 여부 확정 / 금까지 담당자 문제 취합
  - 예외적으로 2주차(11/15/일)에만 일요일에 진행
- cf. 산은 IT 면접 : 뉴스 기사 제시 후 응답하는 방식(주요 IT용어에 대한 꼬리물기 질문)
- 경인 : 모여서 문풀 및 채점, 서술형 연습이 필요하기 때문
- 성욱 : 서인님과 동일, 정량적 점수 산출해볼 것, 문풀 후 피드백
- 수연 : 해설 작성 시 채점기준 AI로 명확히할 것(키워드 등)
- 소정 : 출제 기준 명확해 지면 각자 채점
