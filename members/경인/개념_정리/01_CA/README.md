# 전자계산기구조 (CA)

금융 공기업 전산직 필기시험을 준비하면서 컴퓨터 구조를 정리하는 폴더다. 

우선 공통으로 공부할 범위를 잡고, 이후 지원 기관의 출제 범위와 참고 교재에 맞춰 내용을 보완할 예정이다.

키워드만 외우면 조금 다른 형태의 문제에서 막히는 경우가 있어서, 개념이 어떻게 연결되고 실제로 어떻게 동작하는지까지 정리하려고 한다.
