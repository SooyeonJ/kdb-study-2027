# 한국산업은행(KDB) IT 전공 스터디 실전 문제지 (DS · 알고리즘 집중 세트)

- **문항 구성**: 논술형 1문항(40점, 소문항 4개) + 약술형 2문항(각 4점) — **총 48점 만점**
- **권장 풀이 시간**: 35분 (1번 25분 / 2번·3번 각 5분)

## 1. [논술형] Greedy, DP — 0-1 배낭 채우기 문제 (40점)

최대 허용 무게가 **5kg**인 배낭에 물품을 담아 전체 가치의 합을 최대화하고자 한다. 각 물품은 **1개씩만** 존재하며(쪼갤 수 없음), 물품별 무게($W_i$)와 가치($V_i$)는 다음 표와 같다.

| 물품 ($i$) | 무게 ($W_i$, kg) | 가치 ($V_i$, 만 원) | 단위 무게당 가치 ($V_i / W_i$, 만 원/kg) |
| :---: | :---: | :---: | :---: |
| **A ($i=1$)** | 1 | 6 | 6.0 |
| **B ($i=2$)** | 2 | 10 | 5.0 |
| **C ($i=3$)** | 3 | 12 | 4.0 |
| **D ($i=4$)** | 3 | 9 | 3.0 |

**1-1. (10점)** **분할 가능 배낭 문제(Fractional Knapsack Problem)**와 **0-1 배낭 문제(0-1 Knapsack Problem)**의 개념과 차이점을 설명하고, 각 문제를 해결하기에 적합한 알고리즘(**탐욕 알고리즘 vs 동적 계획법**)과 그 이유를 **최적 부분 구조(Optimal Substructure)** 및 **탐욕적 선택 속성(Greedy Choice Property)** 관점에서 서술하시오.

**1-2. (10점)** 주어진 표에서 **'단위 무게당 가치($V_i / W_i$)가 높은 물품부터 순서대로 배낭에 담는 탐욕 알고리즘(Greedy Algorithm)'**을 적용할 때(단, 남은 배낭 용량보다 무거운 물품은 건너뛰고 다음 순위 물품을 검사함), 선택되는 물품 조합, 총 무게, 총 가치를 단계별로 구하시오. 또한 이 결과가 최적해(최대 가치)가 되지 못하는 이유를 설명하시오.

**1-3. (12점)** 0-1 배낭 문제를 해결하는 다음 동적 계획법(DP) 점화식에서 `DP[i][w]`의 의미와 두 항 `DP[i-1][w]`, `V[i] + DP[i-1][w - W[i]]`의 의미를 각각 설명하시오. 그리고 $i=1 \sim 4$ (물품 A~D), $w=0 \sim 5$에 대한 **`DP[i][w]` 테이블을 모두 채운 뒤**, **최대 가치**와 이를 달성하는 **물품 선택 조합**을 제시하시오.

```text
DP[i][w] = DP[i-1][w]                                      (단, W[i] > w 인 경우)
DP[i][w] = max( DP[i-1][w],  V[i] + DP[i-1][w - W[i]] )    (단, W[i] <= w 인 경우)
(초기 조건: 모든 w에 대해 DP[0][w] = 0, 모든 i에 대해 DP[i][0] = 0)
```

**1-4. (8점)** 물품의 개수를 $N$, 배낭의 최대 허용 무게를 $K$라 할 때, **단순 재귀(완전 탐색) 알고리즘**과 **동적 계획법(DP)**의 동작 방식을 비교 설명하고, 각각의 **시간복잡도와 공간복잡도**를 서술하시오. (추가로 2차원 배열 대신 1차원 배열 `DP[w]`를 사용하여 공간복잡도를 최적화할 때, 무게 $w$의 반복문 진행 방향을 역순($K \rightarrow W_i$)으로 순회해야 하는 이유를 서술하시오.)

## 2. [약술형 - 자료구조(DS)] 최소 힙(Min-Heap) 삽입·삭제 및 우선순위 큐 (4점)

비어 있는 **최소 힙(Min-Heap)**에 키(Key) 값 **`30, 20, 10, 40, 15`**를 순서대로 삽입한 후, 최솟값(루트 노드)을 꺼내는 `deleteMin()` 연산을 **1회** 수행하고자 한다. (단, 힙은 루트 노드의 인덱스가 `1`번인 1차원 배열 기반 완전 이진 트리로 구현한다.)

**2-1. (2점)** ① 5개의 키를 모두 삽입한 직후의 상태와, ② 이후 `deleteMin()`을 1회 수행 완료한 직후의 상태를 각각 **1차원 배열(인덱스 1번부터 레벨 순서대로 나열)** 또는 **완전 이진 트리 구조**로 작성하시오.

**2-2. (2점)** 원소 수가 $N$개인 최소 힙에서 단일 원소의 **삽입(Insertion)**과 **최솟값 삭제(Deletion)** 연산의 시간복잡도를 쓰고, **정렬되지 않은 일반 배열(Unsorted Array)**로 구현한 우선순위 큐와 두 연산의 시간복잡도를 비교하시오.

## 3. [약술형 - 알고리즘(AL)] 최소 신장 트리(MST): Kruskal vs Prim (4점)

5개의 정점 $V = \{A, B, C, D, E\}$를 연결하는 무방향 가중치 그래프의 간선과 가중치가 다음과 같이 주어져 있다.
- `(A, B) = 1`, `(B, C) = 2`, `(A, C) = 3`, `(C, D) = 4`, `(B, D) = 5`, `(D, E) = 6`, `(C, E) = 7`

**3-1. (2점)** 위 그래프에서 **크루스칼(Kruskal) 알고리즘**을 적용할 때 간선이 검사되는 순서대로 **채택(O) / 기각(X, 사이클 발생 여부)** 과정을 쓰고, 완성된 최소 신장 트리(MST)의 **총 가중치 합**을 구하시오.

**3-2. (2점)** **크루스칼(Kruskal) 알고리즘**과 **프림(Prim) 알고리즘**의 동작 방식 차이(간선 중심 vs 정점 중심, 크루스칼에서 사이클 판별에 사용하는 자료구조)를 설명하고, 정점 수 $|V|$, 간선 수 $|E|$일 때 **희소 그래프(Sparse Graph)**와 **밀집 그래프(Dense Graph)**에서 각각 어느 알고리즘이 더 유리한지 쓰시오.
