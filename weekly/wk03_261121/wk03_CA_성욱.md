# 3주차 CA 문제 - 캐시 계층(L1·L2)과 평균 메모리 접근 시간

- 회차: 2026.11.21(토) / 3주차
- 출제자: 성욱
- 과목: CA(전자계산기구조)
- 유형: 계산·서술 복합형 / 총 15점 / 소문항 3개
- 구분: 산업은행·한국은행 복기 출제 유형을 참고한 신규 예상문제(기출 원문 아님)

## 제1문. [CA] 캐시 계층과 평균 메모리 접근 시간(AMAT) (15점)

KDB 코어뱅킹 서버의 프로세서를 교체하려 한다. 이 프로세서는 **32비트 주소**를 사용하고 1워드는 4B이며, 캐시 계층은 다음 표와 같다.

| 구분 | L1 데이터 캐시 | L2 캐시 | 주기억장치 |
|---|---|---|---|
| 용량 | 32KB | 256KB | — |
| 블록(라인) 크기 | 32B | 32B | — |
| 사상 방식 | 직접 사상(direct-mapped) | 4-way 세트 연관 | — |
| 적중 시 접근 시간 | 1 ns | 10 ns | 100 ns |
| 지역(local) 미스율 | **6%** | **20%** | — |

**공통 조건**

- 캐시 접근은 **계층적(hierarchical)** 방식으로 **L1 → L2 → 주기억장치** 순서로 이루어지며, L2는 L1의 내용을 모두 포함하는 **포함(inclusive)** 관계이다.
- 태그 비교·주소 사상·캐시 관리에 걸리는 부가 시간은 각 계층의 접근 시간에 이미 포함된 것으로 본다.
- 이 서버가 처리하는 트랜잭션은 성격이 다른 두 가지이다. **(A)** 영업점·모바일의 **계좌 잔액 조회·갱신** — 수백만 계좌 중 임의의 한 건을 찾아 소량씩 처리. **(B)** 야간 **배치 정산** — 그날의 거래내역을 파일 순서대로 끝까지 읽어 집계.
- 아래 수치는 모두 문제 계산을 위한 가정값이다.

**1-1. (5점) L1 캐시 하나만 고려할 때**

- **가)** L1의 **캐시 라인 수**와 **태그·인덱스·오프셋 필드의 비트 수**를 구하고, 32비트 주소 **0x0001A4C8**을 세 필드로 분해하여 각 필드의 값을 쓰시오. **(2점)**
- **나)** L1과 주기억장치만 있는 **1단계 캐시 환경**에서의 **평균 메모리 접근 시간(AMAT)** 을 식과 함께 계산하시오. 이어서 **1,000회 접근**에 걸리는 총시간과 그중 **주기억장치 대기 시간의 비중**을 구하고, L1 적중 시간이 1 ns → 2 ns로 늘어나면 AMAT가 어떻게 변하는지 쓰시오. **(3점)**

**1-2. (5점) L2 캐시까지 고려할 때**

- **가)** L1 미스 시 발생하는 **L1 미스 페널티(miss penalty)** 를 L2 적중 시간과 L2 미스율로 구성하여 계산하시오. 또한 L2의 **전역(global) 미스율**을 구하고, 이것이 표에 주어진 L2의 **지역(local) 미스율 20%** 와 어떻게 다른지 쓰시오. **(2점)**
- **나)** L1 → L2 → 주기억장치의 **2단계 계층에서의 AMAT** 를 식과 함께 계산하고, 1-1의 L1 단독 결과와 비교하여 **개선 폭(ns·%·배수)** 을 구하시오. 이어서 개선 폭이 왜 이만큼 커지는지 **미스 페널티의 감소**와 **주기억장치 접근 빈도의 변화** 관점에서 분석하시오. **(3점)**

**1-3. (5점) 여러 조건을 변형해 볼 때** — 아래 각 조건은 **1-2의 결과(AMAT 2.8 ns)를 기준**으로, 해당 조건만 바꾼 것으로 계산한다.

- **가)** 다음 세 가지 개선안을 각각 적용했을 때의 **AMAT와 감소 폭**을 구하고, **어느 개선이 가장 효율적인지** 비용 관점의 근거와 함께 고르시오. 또한 ①을 위해 L1을 4-way로 올리면 L1 적중 시간이 1 ns → 1.2 ns로 늘어날 때, ①의 실제 이득이 어떻게 달라지는지 쓰시오. **(2점)**
    - ① L1 지역 미스율 6% → **4%** (연관도 상향·프리페치)
    - ② L2 적중 시간 10 ns → **5 ns** (L2 SRAM 고속화)
    - ③ L2 지역 미스율 20% → **10%** (L2 용량 2배)
- **나)** L1·L2의 **블록 크기를 32B → 64B**로 2배 확대한다. **세트 수와 태그·인덱스·오프셋 비트 수**의 변화를 쓰고, 공간 지역성 덕분에 L1 미스율이 6% → **5%** 로 낮아지는 반면 블록 전송량이 2배가 되어 계층 간 접근 시간도 2배(**L2 20 ns, 주기억장치 200 ns**)가 된다고 할 때의 **AMAT** 를 계산하시오. 이어서 블록 확대가 **이득이 되는 손익분기 미스율**을 구하고, 이 워크로드에 확대를 적용할지 판단하시오. **(2점)**
- **다)** 계좌 갱신 트랜잭션은 메모리 접근의 **30%가 쓰기**이다. 쓰기 버퍼가 지연을 흡수하지 못한다고 가정할 때 **write-through**로 운용하면 AMAT가 얼마가 되는지 계산하고, **write-back(write-allocate)** 과 비교하여 이 워크로드에 적합한 정책을 근거와 함께 고르시오. **(1점)**
