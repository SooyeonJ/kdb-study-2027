## 문제 2. C언어 코드 분석

다음 C 프로그램을 분석하고 물음에 답하시오.

```c
#include <stdio.h>

void update(int *p, int n) {
    for (int i = 0; i < n; i++) {
        *(p + i) += i;
    }
}

int main(void) {
    int a[] = {2, 4, 6, 8};
    int *p = a;

    update(a, 4);

    printf("%d %d\n", a[2], *(p + 3));
    return 0;
}
```

**(1) [5점]** 프로그램 실행 결과를 작성하고, 배열 `a`의 최종 원소를 순서대로 나타내시오.

**(2) [5점]** 다음 설명 중 **옳은 것을 모두** 고르시오.

- **ㄱ.** `p + 1`은 `p`가 가리키는 주소에서 `sizeof(int)`바이트만큼 이동한 주소를 나타낸다.
- **ㄴ.** `update()` 함수에서 `p`가 가리키는 배열 원소를 변경하면 `main()`의 배열 `a`에도 반영된다.
- **ㄷ.** `*(p + i)`와 `p[i]`는 동일한 원소를 참조한다.
- **ㄹ.** `update(a, 4)` 호출 시 배열 `a`의 모든 원소가 새로운 배열에 복사되어 전달된다.

**(3) [5점]** C언어에서 포인터를 이용한 함수 인자 전달과 값에 의한 전달(call by value)의 관계를 설명하고, `update()` 호출 이후 원본 배열의 값이 변경되는 이유를 서술하시오.
