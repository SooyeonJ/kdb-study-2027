## 제2문. [PL·NW] Python·Java 코드 해석 (15점)

금융기관 A는 제1문에서 설계한 서브넷 중 `192.168.10.130` 주소가 속한 네트워크를 확인하는 프로그램을 작성하고 있다. 다음 Python 및 Java 코드를 보고 물음에 답하시오.

### [가] Python

```python
ip = 130
mask = 224
prefix = "27"

print(ip & mask)
print(prefix * 2)
```

### [나] Java

```java
public class Main {
    public static void main(String[] args) {
        int ip = 130;
        int mask = 224;
        int prefix = 27;

        System.out.println(ip & mask);

        prefix = "27";

        System.out.println(prefix);
    }
}
```

**2-1. (5점)** [가] Python 코드의 출력 결과를 순서대로 작성하고, 비트 AND 연산이 IP 주소의 네트워크 부분을 추출하는 원리를 설명하시오.

**2-2. (5점)** [나] Java 코드의 컴파일 또는 실행 과정에서 발생하는 문제를 찾아 원인을 설명하시오. 또한 코드를 정상 실행하도록 수정하고 그 출력 결과를 작성하시오.

**2-3. (5점)** 다음 설명 중 **옳은 것을 모두 고르고**, **옳지 않은 설명은 그 이유**를 작성하시오.

- **ㄱ.** `192.168.10.130/27`이 속하는 네트워크 주소는 `192.168.10.128`이다.
- **ㄴ.** Java에서 `int` 변수에 문자열 `"27"`을 대입하면 컴파일은 성공하지만 실행 중 예외가 발생한다.
- **ㄷ.** Python에서 문자열 `"27"`에 정수 `2`를 곱하면 문자열 반복 연산이 수행된다.
- **ㄹ.** `/27` 서브넷은 네트워크 주소와 브로드캐스트 주소를 제외하고 32개의 호스트 주소를 사용할 수 있다.
