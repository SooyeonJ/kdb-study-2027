# 3주차 NW 문제 - IPv4 서브넷 설계

- 회차: 2026.11.21(토) / 3주차
- 출제자: 수연
- 과목: NW(데이터통신·네트워크)
- 유형: 서브넷 계산형 / 총 15점 / 소문항 3개
- 구분: 산업은행 복기 출제 유형을 참고한 신규 예상문제(기출 원문 아님)

## 제1문. [NW] IPv4 서브넷 설계 (15점)

금융기관 A는 `192.168.10.0/24` 네트워크를 업무망별로 분리하려고 한다. 각 서브넷은 **최소 16개의 호스트를 수용**해야 하며, **가능한 한 많은 서브넷**을 생성하고자 한다.

단, 각 서브넷의 네트워크 주소와 브로드캐스트 주소는 호스트에 할당하지 않는다.

**1-1. (5점)** 조건을 만족하는 서브넷의 프리픽스 길이와 서브넷 마스크를 구하고 계산 과정을 작성하시오.

**1-2. (5점)** 생성할 수 있는 최대 서브넷 개수와 각 서브넷에서 사용 가능한 호스트 주소 수를 계산하시오.

**1-3. (5점)** 생성된 서브넷을 네트워크 주소의 오름차순으로 정렬했을 때, **다섯 번째 서브넷**의 네트워크 주소, 브로드캐스트 주소 및 사용 가능한 호스트 주소 범위를 구하시오.
