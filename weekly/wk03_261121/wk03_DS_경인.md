## 문제 1. [논술형] 방향 그래프의 최단 경로 (40점)

다음은 정점 집합이 {S, A, B, C, D, T}인 방향 가중치 그래프의 간선 목록이다. 간선의 방향은 출발 정점에서 도착 정점으로 향하며, 표에 없는 간선은 존재하지 않는다.

| 출발 정점 | 도착 정점 | 가중치 |
|---|---|---:|
| S | A | 4 |
| S | B | 2 |
| B | A | −1 |
| B | C | 5 |
| B | D | 4 |
| A | C | 3 |
| A | D | 2 |
| C | D | −2 |
| C | T | 4 |
| D | T | 3 |

출발 정점은 S이다. d[v]는 S에서 v까지 현재까지 발견한 최단 거리이며, 초기값은 d[S] = 0, 나머지는 ∞이다. parent[v]는 최단 경로 복원을 위한 직전 정점을 나타내며, 초기값은 모두 NIL이다.

### 1-1. 알고리즘 선택 (10점)

가) 이 그래프에서 BFS를 사용하여 최소 가중치 경로를 구하는 것이 적절한지 판단하고, 간선 수가 적은 경로와 가중치 합이 작은 경로를 비교하여 설명하시오. **(4점)**

나) 방문 정점의 거리를 확정한 뒤 다시 변경하지 않는 일반적인 다익스트라 알고리즘을 음수 간선이 있는 그래프에 항상 적용할 수 있는지 설명하시오. 이 그래프에서 활용할 수 있는 구조적 특성과, 이를 이용한 최단 경로 계산 방법을 제시하시오. **(6점)**

### 1-2. 최단 경로 계산 (10점)

가) 이 그래프의 위상 정렬 순서를 하나 제시하시오. **(2점)**

나) 가)의 순서대로 각 정점의 나가는 간선을 완화(relaxation)하시오. 각 정점의 처리가 끝난 직후 d[S], d[A], d[B], d[C], d[D], d[T]를 표로 작성하시오. **(5점)**

다) S에서 T까지의 최단 거리와 경로를 구하고, 경로에 포함되는 각 정점의 parent 값을 제시하시오. **(3점)**

### 1-3. 최단 경로의 점화식과 계산 순서 (12점)

가) S에서 정점 v까지의 최단 거리를 D(v)라 하자. v로 들어오는 간선과 선행 정점의 최단 거리를 이용하여 D(v)를 구하는 점화식과 초기 조건을 작성하시오. 또한 정점 D에 이 점화식을 적용하여 각 후보 경로의 비용과 최솟값을 구하시오. **(4점)**

나) 위상 순서 대신 S → A → B → C → D → T 순서로 각 정점의 나가는 간선을 한 번씩만 완화할 때, 최종적으로 계산되는 d[T]를 구하시오. 올바른 최단 거리와 차이가 발생하는 이유를 설명하고, 위상 순서로 처리하면 음수 간선이 있어도 이러한 문제가 발생하지 않는 이유를 서술하시오. **(4점)**

다) 인접 리스트를 사용하는 위상 정렬 기반 최단 경로 알고리즘의 전체 시간복잡도와 입력 그래프 저장 공간을 제외한 보조 공간복잡도를 구하시오. 단, 위상 정렬에 필요한 비용도 포함한다. **(4점)**

### 1-4. 그래프 변경과 음수 사이클 (8점)

기존 그래프에 가중치가 −1인 방향 간선 D → B를 추가하였다.

가) 변경된 그래프에 위상 정렬 기반 최단 경로 알고리즘을 그대로 적용할 수 있는지 판단하고, S에서 T까지 유한한 최단 거리가 존재하는지 구체적인 사이클과 그 가중치 합을 근거로 설명하시오. **(4점)**

나) 변경된 그래프에 벨만–포드 알고리즘을 적용할 때, 출발점에서 도달 가능한 음수 사이클을 검출하는 절차와 최악 시간복잡도를 설명하시오. 또한 출발점에서 도달 가능한 음수 사이클의 존재가 특정 목적지의 최단 거리에도 영향을 주기 위한 조건을 쓰시오. **(4점)**

## 문제 2. [서술형] 해시 테이블의 충돌과 삭제 (10점)

크기가 7인 빈 해시 테이블에 다음 키를 순서대로 삽입한다. 인덱스는 0~6이며, 해시 함수는 h(k) = k mod 7이다. 충돌은 선형 조사법으로 해결하고, 인덱스 6 다음에는 0으로 돌아간다.

```text
10, 17, 24, 8, 15
```

### 2-1. (5점)

가) 각 키가 저장되는 인덱스와 모든 삽입이 끝난 후의 해시 테이블을 작성하시오. **(3점)**

나) 완성된 테이블에서 키 24를 검색할 때 확인하는 인덱스를 순서대로 쓰고, 확인하는 슬롯 수를 구하시오. **(2점)**

### 2-2. (5점)

가) 위 테이블에서 키 17을 삭제한 자리를 한 번도 사용하지 않은 빈 슬롯(EMPTY)으로 변경하였다. 검색은 EMPTY를 만나면 실패로 종료한다. 이때 키 24를 검색하는 과정과 결과를 쓰고, 발생한 문제의 원인을 설명하시오. **(3점)**

나) 삭제 자리에 별도의 삭제 표시(DELETED)를 남기는 방식에서 검색과 삽입이 이 표시를 어떻게 처리해야 하는지 설명하시오. 단, 테이블에는 중복 키를 허용하지 않는다. **(2점)**
