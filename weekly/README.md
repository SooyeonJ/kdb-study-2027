# 📅 주차별 스터디

정기 모임에서 사용할 예상문제와 해설을 모으는 공간입니다.

## 📝 기록 방법

- 주차별 폴더를 만들어 문제와 해설 업로드
- 파일명에 출제자 이름 포함
- 문제와 해설은 파일을 분리하여 작성
- 모임에서 나온 질문이나 수정 사항은 해당 주차에 정리

## 회차별 폴더 명명 규칙

- 형식 : `wkNN_YYMMDD` (예 : `wk01_261107`)
- 회차는 `wk01`, `wk02` 순으로 증가하고 날짜는 실제 모임 기준
